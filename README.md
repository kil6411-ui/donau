# 돈암1동 이웃살핌

혼자 계신 이웃이 걱정될 때 주민이 복지관에 알리는 앱.
길음종합사회복지관 마을동행팀 · 돈암1동 시범.

---

## 어떻게 도는가

```
주민이 앱에서 알림 → 구글 폼 → 구글 시트 (담당자만 열람)
                                    ↓
                     담당자 확인 → 방문 → 주민센터 연계
```

**앱은 받기만 하고 아무것도 보여주지 않습니다.**
관리자 화면을 앱에 만들지 않은 이유는, 이런 정적 웹앱에는 진짜 로그인이 없어
비밀번호를 넣어도 소스만 열면 다 보이기 때문입니다.
**열람 통제는 구글 시트의 공유 권한으로 합니다.** 이게 진짜 자물쇠입니다.

---

## 파일

| 파일 | 하는 일 | 손댈 일 |
|---|---|---|
| `index.html` | 앱 전체 | 설정값 수정 시 |
| `sw.js` | 오프라인·설치 | 내용 고칠 때 버전만 |
| `manifest.json` | 앱 이름·아이콘 | 거의 없음 |
| `vercel.json` | 배포 설정 | 없음 |
| 아이콘 4개 | 홈 화면 아이콘 | 복지관 CI로 교체 시 |

## 배포 (처음 한 번)

### 1) GitHub에 올리기

github.com → 새 저장소 → **Add file → Upload files** →
파일 전부 끌어다 놓기 → **Commit changes**.

폴더째 말고 **파일만** 올리세요. `index.html`이 저장소 맨 위층에 있어야 합니다.

### 2) Vercel 배포

vercel.com → GitHub 로그인 → **Add New → Project** → **Import** → **Deploy**.

1분 뒤 주소가 나옵니다. 이게 주민에게 알려줄 주소입니다.
`Settings → Domains` 에서 알아보기 쉬운 이름으로 바꿔두면 좋습니다.

### 3) QR 만들어 배포

경로당 게시판, 아파트 엘리베이터, 통장님 통해 배포.
**종이에도 복지관 번호를 같이 찍으세요.** 스마트폰 없는 분들이 있습니다.

## 신고 접수 켜기

`FORM.id` 가 비어 있으면 신고 화면 맨 아래가 **전화 접수 안내**로 바뀝니다.
그 상태로도 앱은 정상 작동하니, 아래 준비가 끝난 뒤 켜시면 됩니다.

### 1) 구글 폼 만들기

forms.google.com → 새 폼. 질문 9개를 **모두 단답형 또는 장문형**으로.
(객관식으로 만들면 앱에서 보낸 값이 거부됩니다)

| 순서 | 질문 | 형식 |
|---|---|---|
| 1 | 걱정되는 분 성함 | 단답형 |
| 2 | 사시는 곳 | 단답형 |
| 3 | 연락처 | 단답형 |
| 4 | 연세 | 단답형 |
| 5 | 본인 연락 동의 여부 | 단답형 |
| 6 | 추천 이유 | 단답형 |
| 7 | 자세한 내용 | 장문형 |
| 8 | 추천하신 분 성함 | 단답형 |
| 9 | 추천하신 분 연락처 | 단답형 |

### 2) entry 번호와 폼 id 찾기

폼 편집 화면 우측 상단 **미리보기** 를 누르고, 열린 페이지에서
우클릭 → **페이지 소스 보기** → `Ctrl+F` 로 `entry.` 검색.
`entry.123456789` 형태 숫자가 질문 순서대로 6개 나옵니다.

미리보기 주소가 `.../forms/d/e/1FAIpQL.../viewform` 이면 `1FAIpQL...` 이 id 입니다.

### 3) `index.html` 에 넣기

```js
const FORM = {
  id: "1FAIpQL...",
  fields: {
    name:        "entry.111111111",
    addr:        "entry.222222222",
    tel:         "entry.333333333",
    age:         "entry.444444444",
    consent:     "entry.555555555",
    reasons:     "entry.666666666",
    detail:      "entry.777777777",
    reporter:    "entry.888888888",
    reporterTel: "entry.999999999"
  }
};
```

### 4) 알림 켜기

구글 폼 [응답] 탭 → 점 세 개 → **새 응답에 대한 이메일 알림 받기**.
**이 채널은 이걸 반드시 켜야 합니다.**

## 시트 잠그기 — 가장 중요

> 이 앱은 **동의하지 않은 제3자의 성함·주소·연락처**를 수집합니다.
> 자원 정보와는 무게가 완전히 다릅니다. 아래를 반드시 지키세요.

- **절대 '웹에 게시' 하지 마세요.** 한 번 게시하면 주소만 알면 누구나 봅니다.
- 공유 설정을 **'제한됨'** 으로 두고 **담당자 2~3명만** 개별 초대.
- **기관 구글 계정**으로 만드세요. 개인 계정에 두면 퇴사 시 승계가 안 됩니다.
- 다운로드·인쇄·복사 제한 옵션을 켜두세요.

## 운영 규칙 (열기 전에 문서로)

**법적 근거.** 사회보장급여법의 지원대상자 발굴 신고 조항이 근거가 됩니다.
다만 공식 창구는 129와 주민센터이므로, **복지관 접수 건을 언제 공공으로
이첩할지** 기준을 정하고 주민센터와 미리 합의해 두세요.

**기관 내부 승인.** 이 기능은 기관의 개인정보 처리 범위를 넓힙니다.
**기관장 결재와 개인정보 처리방침 반영을 먼저 받으세요.**

**확인 주기.** 최소 주 2회. 담당자 1명 + 백업 1명.

**위급 건.** 앱이 119를 먼저 안내하지만 그래도 들어올 수 있습니다.
발견 즉시 어떻게 할지 정해두세요.

**보관 기간.** 1년 등으로 정하고 지나면 삭제. 처리 완료 건도 마찬가지.

**오남용 대비.** 이웃 갈등, 층간소음, 특정인 표적화 제보가 들어옵니다.
앱에 "다툼이나 소음은 주민센터로"라고 써뒀지만 완전히 막히지 않습니다.
담당자가 걸러내는 기준을 정해두세요.

**시범 평가.** 돈암1동에서 3~6개월. 접수 건수, 실제 발굴로 이어진 비율,
오남용 비율을 정리하면 확대 여부 판단 근거가 됩니다.

## 내용 고치기

GitHub에서 `index.html` → 연필 아이콘 → 수정 → **Commit changes**. 1분이면 반영.

고칠 만한 곳은 파일 맨 위 설정 구역에 모여 있습니다.

- `AREA` `TONGS` — 시범 지역과 통 목록
- `CENTER` `HELP` `DONG` — 연락처
- `HOURS` — 업무 시간 (토요일 근무가 있으면 `days` 에 `6` 추가)
- `REASONS` — 추천 이유 네모 항목
- `CONSENTS` — 본인 연락 동의 선택지
- `GUIDE` — "어떤 경우에 알려야 하나요" 안내문
- `FAQ` — 자주 묻는 질문

### 고친 뒤에는 반드시

`sw.js` 맨 위 `const VERSION = "v2";` 의 숫자를 올립니다. `"v3"`, `"v4"` ...

**빠뜨리면 이미 앱을 담아둔 주민 휴대폰에 옛날 내용이 계속 뜹니다.**

## 잘 안 될 때

| 증상 | 원인 |
|---|---|
| 신고 버튼 대신 전화 안내가 뜸 | `FORM.id` 가 비어 있음 (정상 동작) |
| 보냈는데 시트에 안 쌓임 | entry 번호가 틀렸거나 질문이 객관식 |
| "홈 화면에 담기"가 없음 | 아이폰은 정상. 안드로이드면 이미 설치된 상태 |
| 고쳤는데 그대로임 | `sw.js` VERSION을 안 올림 |
| 파일 더블클릭하니 설치가 안 됨 | 정상. https 주소에서만 작동 |
