# 돈암1동 복지지도

주민이 "이럴 땐 어디로 가야 하나"를 바로 찾는 동네 복지 안내 웹앱.
길음종합사회복지관 마을동행팀.

## 폴더에 들어있는 것

| 파일 | 하는 일 | 손댈 일 |
|---|---|---|
| `index.html` | 앱 전체 (화면 + 자원 정보) | **자주** |

## 배포하기 (처음 한 번)

### 1단계 — GitHub에 올리기

github.com에서 새 저장소를 만듭니다. 이름은 `donam1-map` 정도.
Public / Private 아무거나 상관없습니다.

만든 저장소에서 **Add file → Upload files**를 누르고
이 폴더의 파일 전부를 끌어다 놓은 뒤 **Commit changes**.

> 폴더째로 올리지 말고 **파일들만** 올려야 합니다.
> `index.html`이 저장소 맨 위에 있어야 합니다.

### 2단계 — Vercel에 연결

vercel.com에 GitHub 계정으로 로그인 →
**Add New → Project** → 방금 만든 저장소 **Import** →
설정 건드리지 말고 **Deploy**.

1분쯤 뒤 `https://donam1-map.vercel.app` 같은 주소가 나옵니다.
이게 앞으로 주민에게 알려줄 주소입니다.

### 3단계 — 카카오 지도 키 넣기

지도를 켜려면 키가 필요합니다. 키 없이도 나머지는 다 작동하니
급하면 이 단계는 나중에 해도 됩니다.

1. developers.kakao.com 로그인 → **내 애플리케이션** → **애플리케이션 추가하기**
2. 만든 앱 → **카카오맵** → **사용 설정**을 **ON**
3. **앱 설정 → 플랫폼 → Web** 에 2단계에서 받은 주소를 등록
   (예: `https://donam1-map.vercel.app`)
4. **앱 키** 화면에서 **JavaScript 키**를 복사
5. GitHub에서 `index.html`을 열고 연필 아이콘(편집) →
   `const KAKAO_KEY = "";` 의 따옴표 안에 붙여넣기 → Commit

> **REST API 키가 아니라 JavaScript 키**입니다. 지도 SDK에 REST API 키를 쓰면 에러가 납니다.
> 무료 쿼터는 계정에서 카카오맵을 처음 켠 앱 하나에만 붙습니다.
> 이미 다른 앱에서 카카오맵을 쓰고 있다면 그 앱 키를 그대로 쓰세요.

### 4단계 — QR 만들어 배포

2단계 주소로 QR을 만들어 전단, 경로당 게시판, 주민센터 안내판에 붙입니다.
QR은 네이버·카카오 QR 생성기 무료로 충분합니다.

> **종이에도 주민센터·복지관 번호를 같이 찍으세요.**
> 스마트폰이 없는 분들이 있습니다. QR은 보조 수단입니다.

## 내용 고치기

`index.html`을 GitHub에서 열고 연필 아이콘으로 편집한 뒤 Commit하면
Vercel이 1분 안에 자동으로 반영합니다.

### 자원 추가·수정

`RESOURCES` 목록에서 아래 모양대로 넣습니다.

```js
{cat:["meal","alone"],
 name:"○○경로당",
 pin:"○○경로당",                    // 지도 이름표 (짧게)
 what:"어르신들이 모여 식사하고 프로그램에 참여합니다.",
 tel:"02-000-0000",
 addr:"서울 성북구 ○○로 00",        // 주소만 정확하면 지도 좌표는 자동
 when:"평일 09:00~18:00",
 who:"동네 어르신"},
```

- `addr`만 정확히 넣으면 **위경도는 카카오가 알아서 찾습니다.**
- 정보가 아직 없으면 `todo:true`를 붙여두면 "정보 확인 중" 표시가 뜹니다. 다 채우면 지우세요.
- `cat`은 `meal / health / money / alone / care / home / mind / report` 중에서 고릅니다. 여러 개 가능합니다.
- 없는 항목은 `""`로 비워두면 화면에서 알아서 빠집니다.

### 주민 이야기함 켜기 (구글 폼 연결)

주민이 앱 안에서 동네 이슈를 남기면 구글 스프레드시트에 자동으로 쌓입니다.
서버도 비용도 필요 없습니다. 20분이면 됩니다.

**1) 구글 폼 만들기** — forms.google.com 에서 새 폼 생성.
질문 4개를 **모두 '단답형' 또는 '장문형'** 으로 만듭니다.
(객관식으로 만들면 앱에서 보낸 값이 거부됩니다)

| 순서 | 질문 제목 | 형식 |
|---|---|---|
| 1 | 이야기 종류 | 단답형 |
| 2 | 장소 | 단답형 |
| 3 | 내용 | 장문형 |
| 4 | 연락처 | 단답형 |

**2) entry 번호 찾기** — 폼 편집 화면에서 우측 상단 **미리보기(👁)** 를 누르고,
열린 페이지에서 마우스 우클릭 → **페이지 소스 보기** →
`Ctrl+F` 로 `entry.` 검색. `entry.123456789` 형태 숫자가 질문 순서대로 4개 나옵니다.

**3) 폼 id 찾기** — 미리보기 주소가
`https://docs.google.com/forms/d/e/1FAIpQL.../viewform` 이면
`1FAIpQL...` 부분이 id 입니다.

**4) `index.html` 에 넣기**

```js
const ISSUE_FORM = {
  id: "1FAIpQL...",
  fields: {
    type:    "entry.111111111",
    where:   "entry.222222222",
    text:    "entry.333333333",
    contact: "entry.444444444"
  }
};
```

넣으면 첫 화면 아래에 "이야기 남기기" 블록이 나타납니다.
비워두면 그 화면 자체가 안 나옵니다.

**5) 알림 켜기** — 구글 폼 [응답] 탭 → 점 세 개 → **새 응답에 대한 이메일 알림 받기**.
이걸 켜야 접수 사실을 바로 압니다.

**통 목록 고치기** — `TONGS` 배열을 돈암1동 실제 통 구성에 맞게 수정하세요.

> **운영 규칙을 먼저 정하고 여세요.**
> 확인 주기(주 1회 등), 담당자, 처리 결과를 어디에 알릴지.
> 접수만 되고 아무도 안 보는 창구가 가장 나쁩니다.

### 동 경계선 그리기 (권장)

주민들과 만든 종이 지도의 하늘색 영역을 지도 위에 얹는 기능입니다.
"여기까지가 우리 동네"를 보여주는 것이라 개인정보가 전혀 없고,
주민이 "이 서비스가 나한테 해당되나"를 판단하는 기준이 됩니다.

1. **geojson.io** 접속 (가입 불필요)
2. 지도를 돈암1동으로 이동
3. 왼쪽 위 다각형(⬠) 도구로 경계를 따라 클릭하며 그리기
4. 왼쪽 창의 `coordinates` 숫자 묶음 복사
5. `index.html` 의 `BOUNDARY` 에 `{lat:위도, lng:경도}` 형태로 붙여넣기

> geojson.io는 **[경도, 위도]** 순서입니다. `[127.0190, 37.6050]` 이면
> `{lat:37.6050, lng:127.0190}` 으로 **뒤집어서** 넣으세요.
> 점은 20~40개면 충분합니다.

### 자원 사진 넣기

어르신에게 "삼양로2길 55"는 의미가 없지만 가게 외관 사진은 즉시 알아봅니다.
사진 파일을 저장소에 올리고 자원에 `photo` 한 줄을 추가하면 카드 위에 뜹니다.

```js
{kind:"share", cat:["meal"], name:"○○상회",
 photo:"shop-1.jpg",
 ...}
```

- **얼굴이 나온 사진은 쓰지 마세요.** 외관 위주로.
- 가게 사진은 사장님 동의를 먼저 받으세요.
- 가로 800px 정도로 줄여서 올리세요. 원본은 무겁습니다.

### 손그림 동네지도 넣기

주민 공개용으로 다시 만든 이미지를 저장소에 올리고
`POSTER` 의 `src`에 파일 이름을 적습니다.

```js
const POSTER = { src: "donam1-map.png", caption: "..." };
```

원본에서 반드시 지우고 올릴 것: 쓰레기집 위치, 쉐어하우스 위치,
개인 얼굴 사진, 주민 이슈 메모(재개발 관련 포함), 나눔가게 상호.

### ⚠️ 고친 뒤에는 반드시

`sw.js` 맨 위 `const VERSION = "v1";` 의 숫자를 올립니다. `"v2"`, `"v3"` ...

**이걸 빠뜨리면 이미 앱을 담아둔 주민 휴대폰에 옛날 내용이 계속 뜹니다.**
PWA에서 제일 흔한 사고입니다. 자원 정보 수정과 세트로 기억하세요.

## 잘 안 될 때

| 증상 | 원인 |
|---|---|
| 지도 자리에 안내문만 뜸 | 카카오 키가 비었거나, 플랫폼에 도메인 등록을 안 함 |
| 지도가 회색이고 에러 | REST API 키를 넣었을 가능성. JavaScript 키로 교체 |
| 특정 자원이 지도에 안 뜸 | `addr` 주소가 부정확. 카카오맵에서 검색되는 형태로 |
| "홈 화면에 담기" 버튼이 없음 | 아이폰은 정상(공유→홈 화면에 추가 안내가 대신 뜸). 안드로이드인데 없으면 이미 설치된 상태 |
| 고쳤는데 그대로임 | `sw.js` VERSION을 안 올림 |
| 파일 더블클릭했더니 지도·설치가 안 됨 | 정상. 둘 다 https 주소에서만 작동 |
